# My Workspace Hub

Создай сервис работающий как рабочее пространство сотрудника компании с различными инструментами и возможностями для эффективной работы. Дизайн в стиле логотипа сервиса который я приложил изображением(светлая и темная темы). В сервисе должна быть авторизация по почте с подтверждением или через сервисы гугл автоматическая регистрация и вход. Нужна возможность подключения специального  бота телеграм, который так же будет иметь разный функционал в зависимости от того, какого отдела является сотрудник. так же в сервисе нужен спец профиль админка, для регулирования ролей пользователей(сотрудники разных отделов), редактирования пользователей и отделы, редактирования доступных инсрументов для того или иного пользователя или целого отдела, добавление новых инстурментов и редактирование, добавление сервисов в виде ссылки и короткого описания,настройки функционала бота телеграм для каждого сотрудника или целого отдела,настройки рабочего времени графиков смен, других важных в работе системы настроек которые не описаны в тексте но нужны по логике вещей. Само рабочее пространство выглядит примерно как на втором приложенном скрине. Обязательно должна быть мобильная версия.
